Burin

A Resolume plugin that draws vector artwork at the resolution the frame actually needs, and rebuilds it when that changes — so going in close stays sharp instead of turning into a bitmap. Drop your own SVG anywhere on this page. Nothing is uploaded; the file is read in your browser and stays there.

The readout is the point as much as the picture is. wants is the resolution this frame needs; rung is what the ladder snapped it to — always upward, so the drawing is never magnified. Drag Zoom and watch rebuilds climb in steps rather than once a frame: that is what makes it affordable.

This demo uses your browser's SVG engine; the plugin uses nanosvg. The decisions are the same — the scale ladder, the cache rule, the reveal timing, the fill and stroke selection are ports of the plugin's own code — but the thing that finally turns paths into pixels is different. The one difference that will bite you: the browser draws <text> and the plugin does not, so convert text to outlines before using a file in Resolume. The demo says so when it sees any.
